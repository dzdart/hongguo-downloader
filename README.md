## 📖 软件简介

本软件是一款专为**红果短剧（番茄小说短剧频道/novelread系）**打造的高效 Windows 桌面级全集批量解析与下载工具。

传统抓取方式只能录屏或抓取到分片加密文件，本工具采用 **Electron + React + Node.js** 现代桌面架构，内置字节系短剧 API 逆向协议与 **CENC-AES-CTR 原生流式解密引擎**，可一键批量解析整部短剧的所有集数，并在下载过程中自动解密生成无水印、高码率的标准 MP4 原画视频。

## 🌟 全部具体功能清单

### 一、 🎬 智能短剧解析与元数据提取

1. **多格式输入自动识别**：
   - 支持直接粘贴红果短剧 App 的**分享链接**；
   - 支持包含引导文案和特殊口令的**长文本自动清洗提取**；
   - 支持直接输入短剧的 **`series_id`**（纯数字剧集 ID）秒级解析。
2. **完整剧集元数据解析**：
   - 自动拉取短剧官方全名、高清竖版封面海报、总集数；
   - 自动获取每集的真实集数序号（如第 1 集、第 2 集……第 100 集）及其分集官方标题；
   - 自动映射每集的唯一视频识别码 (`vid`) 与播放源配置。

---

### 二、 🎯 高度自由的批量选集控制

1. **一键全局选集**：
   - **全选**：解析完成后默认全选整部剧集；
   - **反选**：一键将已选集数与未选集数状态互换；
   - **清空**：一键取消全部选中状态。
2. **高频快捷选集预设**：
   - ⚡ **前 10 集**：快速抓取试看引流钩子集；
   - ⚡ **前 30 集**：批量提取前半部分剧情高潮素材；
   - ⚡ **后 30 集**：快速抓取大结局与完结反转部分。
3. **强大的复合区间语法筛选**：
   - 支持在输入框内自定义输入集数范围，瞬间批量打钩：
     - 单区间示例：`1-50`（自动选中 1 到 50 集）；
     - 多区间复合示例：`1-10, 25, 30-45`；
     - 离散集数示例：`1, 3, 5, 7, 9`。
4. **单集卡片式精细挑选**：
   - 页面以网格徽章卡片展示所有分集，支持随时点击任意单集进行单独勾选/取消。

---

### 三、 🔐 原生底层解密与高速下载引擎

1. **spade_a 密钥派生与 CENC-AES-CTR 实时解密**：
   - 针对红果短剧平台的视频加密保护机制，软件在 Node.js 原生底层内置了专用密钥派生算法；
   - 在数据流写入本地的同时执行 **CENC-AES-CTR 原生流式解密**，直接输出标准非加密的 MP4 视频文件，画质清晰度与官方客户端原画 100% 一致，无需二次转码。
2. **可靠的分片防损机制**：
   - 下载过程中采用 `.part` 临时文件机制，只有完整拉取并解密成功后才重命名为最终 `.mp4` 文件，彻底防止中途断网产生残缺损坏文件。
3. **多并发线程池调节**：
   - 支持自定义设置 1 ~ 10 线程并行下载；
   - 智能队列排队机制，下载完成后自动顺延启动下一集。

---

### 四、 📋 全功能任务管理中心 (Download Manager)

1. **多维度实时任务状态追踪**：
   - 明确展示每个下载任务的状态：**等待中 (Pending)**、**下载中 (Downloading)**、**已完成 (Completed)**、**失败 (Failed)**、**已停止 (Stopped)**。
2. **实时数据动态回显**：
   - 动态更新已下载大小 / 文件总大小（智能单位换算 B / KB / MB / GB）；
   - 实时下载百分比进度条与动态脉冲指示。
3. **强大的任务管控**：
   - **单任务操作**：支持单集暂停、停止、重试、删除；
   - **批量控制**：一键批量选中任务，一键批量停止，一键批量清除任务记录；
   - **一键重试失败项**：网络抖动或接口限流失败的任务，一键自动重试重新加入队列。
4. **一键定位本地文件**：
   - 已完成的任务卡片提供「打开文件夹」快捷按钮，一键调出 Windows 文件资源管理器并直接高亮选定目标视频。

---

### 五、 ⚙️ 系统设置与自定义文件归档规则

1. **自定义下载保存目录**：
   - 支持调用 Windows 原生目录选择框自由挑选存储磁盘（如下载盘、移动硬盘或 NAS 挂载路径）；
   - 软件自动创建标准树状目录层级：`下载目录/红果短剧/剧名/`，多部剧集自动分文件夹规整存放，井井有条。
2. **智能文件命名模板引擎**：
   - 提供丰富的文件命名预设：
     - `剧名 集数`（例如：`九霄霸皇 001.mp4`）；
     - `剧名 集数 标题`（例如：`九霄霸皇 001 重生逆袭归来.mp4`）；
     - `仅剧名`；
   - 支持自定义宏变量自由组合：`{series_title}`、`{vid_index}`、`{ep_title}`。
3. **接口防封限流调节**：
   - 自由配置最大并发下载数（推荐 3~5），兼顾下载极速与接口稳定性。

## 🛠️ 开发者：本地运行与源码构建

### 环境要求
- 操作系统：Windows 10 / 11 x64
- Node.js：>= 18.0.0 (推荐 20.x 或 22.x x64)
- npm：>= 9.0.0

### 本地开发启动

```powershell
# 1. 克隆本仓库
git clone https://github.com/327044572/hongguo-downloader.git
cd hongguo-downloader

# 2. 安装项目依赖
npm install

# 3. 启动开发模式（同时运行 Vite 前端和 Electron 客户端）
npm run dev
```

### 生产打包构建

```powershell
# 编译 React 前端并打包为 Windows x64 NSIS 安装包
npm run build
```

> 打包生成的可执行安装文件位于 `dist/` 目录下。

## 📂 项目代码结构说明

```text
├── main.js                  # Electron 主进程：短剧解析、下载编排、流式解密与文件 I/O
├── preload.js               # 安全渲染进程 IPC 通信桥
├── src/
│   ├── App.jsx              # 桌面应用主界面与侧边栏导航框架

│   │   ├── DownloadManager  # 下载进度看板与多任务管控中心
│   │   ├── Settings.jsx     # 目录选择、命名规则与并发设置
│   │   └── icons.jsx        # SVG 图标库
│   ├── native/
│   │   └── hongguo.js       # 核心逆向协议：短剧 API 解析与 spade_a AES 解密模块
```
