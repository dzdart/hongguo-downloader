## 📖 软件简介

本工具是一款专为**红果短剧（番茄小说短剧频道 / novelread 系）**打造的全集批量解析与下载工具。

传统抓取方式只能录屏或抓取到分片加密文件，本工具采用 **Python + Flask 后端 + React 前端**架构，内置字节系短剧 API 逆向协议与 **CENC-AES-CTR 原生流式解密引擎**，可一键批量解析整部短剧的所有集数，并在下载过程中自动解密生成无水印、高码率的标准 MP4 原画视频。

本版本为 **Web 网页版**：服务端提供网页界面与下载引擎，浏览器访问即可使用，支持 Docker 一键部署。

## 🌟 功能清单

### 一、🎬 智能短剧解析与元数据提取

1. **多格式输入自动识别**：支持粘贴分享链接、含引导文案的长文本自动清洗提取、或直接输入 `series_id`。
2. **完整剧集元数据解析**：自动拉取剧名、封面、总集数，以及每集的集数序号、官方标题与视频识别码 (`vid`)。

### 二、🎯 高度自由的批量选集控制

1. **一键全局选集**：全选 / 反选 / 清空。
2. **快捷预设**：前 10 集、前 30 集、后 30 集。
3. **复合区间语法筛选**：如 `1-50`、`1-10, 25, 30-45`、`1, 3, 5, 7, 9`。
4. **单集卡片式精细挑选**：网格徽章卡片展示，点击任意单集即可勾选/取消。

### 三、🔐 原生底层解密与高速下载引擎

1. **spade_a 密钥派生与 CENC-AES-CTR 实时解密**：输出标准非加密 MP4，画质与官方客户端原画一致，无需二次转码。
2. **可靠的分片防损机制**：`.enc.tmp` 临时文件机制，完整解密成功后才生成最终 `.mp4`。
3. **多并发线程池调节**：支持 1 ~ 10 线程并行下载，智能队列调度。

### 四、📋 全功能任务管理中心

1. **多维度任务状态追踪**：等待中 / 下载中 / 已完成 / 失败 / 已停止。
2. **实时进度回显**：已下载大小 / 总大小、百分比进度条。
3. **任务管控**：单任务暂停、停止、重试、删除；批量停止、批量清除、一键重试失败项。

### 五、⚙️ 系统设置与自定义文件归档

1. **自定义下载保存目录**：自动创建 `下载目录/红果短剧/剧名/` 树状层级。
2. **智能文件命名模板**：`剧名 集数`、`剧名 集数 标题`、`仅剧名`，支持自定义宏变量。
3. **接口防封限流调节**：自由配置最大并发下载数。

## 🐳 Docker 部署（推荐）

```bash
# 1. 克隆仓库
git clone https://github.com/327044572/hongguo-downloader.git
cd hongguo-downloader

# 2. 一键构建并启动（后台运行）
docker compose up -d --build
```

启动后浏览器访问 **http://localhost:8080** 即可使用。

下载的视频文件保存在宿主机 `./downloads/` 目录，应用数据（设置、任务历史）保存在 `./data/` 目录。

### 关键环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 服务监听端口 |
| `DOWNLOAD_DIR` | `/downloads` | 默认下载根目录（容器内路径，应对应挂载卷） |
| `DATA_FILE` | `/app/data/data.json` | 数据持久化文件路径 |

> **关于下载目录**：在「设置」页面填写的是**服务器（容器）内的绝对路径**。Docker 部署时请填写挂载卷路径（如 `/downloads`），并在 `docker-compose.yml` 中确保该目录已通过卷映射到宿主机，否则重启容器后文件可能丢失。

## 🛠️ 本地开发运行

### 环境要求
- Python >= 3.9（推荐 3.11 / 3.12）
- Node.js >= 18.0.0（仅用于编译前端）

### 安装依赖

```bash
# 安装 Python 依赖
pip install -r requirements.txt

# 编译 React 前端到 dist-react/
npm install
npm run build
```

### 启动服务

```bash
# 启动 Flask 服务（默认端口 8080，同时托管前端页面）
python app.py
```

浏览器访问 **http://localhost:8080** 即可使用。

### 前端开发模式（可选）

需要同时修改前端界面时，可启动 Vite 开发服务器（自动代理 `/api` 到后端）：

```bash
# 终端 1：启动后端
python app.py

# 终端 2：启动前端热更新
npm run dev
# 前端：http://localhost:5173
```

## 📂 项目代码结构说明

```text
├── app.py                   # Flask 服务端：短剧解析、下载编排、流式解密、REST API 与 SSE 推送

├── src/                     # React 前端源码
│   ├── api.js               # 前端 fetch + SSE 通信层
│   ├── App.jsx              # 主界面与侧边栏导航框架

├── vite.config.js           # Vite 构建与开发代理配置
├── Dockerfile               # 多阶段 Docker 镜像构建
├── docker-compose.yml       # Docker Compose 编排（含下载目录卷挂载）
└── build/                   # 图标资源
```
